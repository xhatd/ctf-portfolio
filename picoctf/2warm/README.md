### Description

Can you convert the number 42 (base 10) to binary (base 2)?

---

use cyberchef or any other method

| 42 / 2 = | 21 | r 0 |
| --- | --- | --- |
| 21 / 2 = | 10 | r 1 |
| 10 / 2 = | 5 | r 0 |
| 5 / 2 = | 2 | r 1 |
| 2 / 2 = | 1 | r 0 |
| 1 / 2 = | 0 | r 1 |

then from bottom to top put the remainder in order 101010

**Flag:** picoCTF{101010}
